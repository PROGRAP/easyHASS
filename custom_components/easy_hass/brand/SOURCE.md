# Easy-Hass integration icon

Raster exports of the Heroicons outline `home` icon used by the frontend,
colored to match Easy-Hass. Source: `frontend/src/assets/icons/home.svg` in
this repository; upstream: https://github.com/tailwindlabs/heroicons.

Heroicons is licensed under MIT. The license is included beside these exports.
The icon uses no Home Assistant brand assets.
